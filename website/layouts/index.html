Architecture

How it works.

One binary and one folder in your repository, without a hosted service.

  1. {{ partial "icon.html" (dict "name" "grid" "size" 28) }}

    Index

    .pixel/, at your repository root, holds a text index of eligible files Git does not ignore and a code graph of symbols, imports and calls parsed with tree-sitter, built on first use.

  2. {{ partial "icon.html" (dict "name" "bolt" "size" 28) }}

    Stay warm

    A local daemon keeps both open and watches the tree, so answers take milliseconds and follow your edits. No daemon? The command runs in-process.

  3. {{ partial "icon.html" (dict "name" "gauge" "size" 28) }}

    Answer to a budget

    The agent gets the symbols, signatures or lines its question needs, fitted to a token budget, with a marker saying whether the answer is complete.

  4. {{ partial "icon.html" (dict "name" "robot" "size" 28) }}

    Reach the agent

    A CLI plus hooks, not an MCP server. pixel install puts the protocol where each agent reads its instructions, and the agent calls Pixel from the shell it already has.
