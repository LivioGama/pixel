Your agent reads whole files. Pixel hands it the map.

To find one function, your coding agent may open a whole file. Pixel is a local code index it asks for signatures, callers and starting files instead. It gets a map of your repo, then reads the relevant code.

Try Pixel on your repo

Before you install: read the script. No sudo; it checks the archive’s checksum and writes the binary to ~/.local/bin/pixel. Homebrew and agent-assisted setup are available too.

Free and MIT · macOS on Apple Silicon and Linux · no account, no binary telemetry · pixel uninstall undoes the agent setup

Why Pixel

Finding its way takes context.

A search finds a match. Your agent still has to understand the file around it, find the callers and decide where to start.

  • Context

    The question was one function.

    A whole-file read brings unrelated lines into the agent’s context. An outline shows what the file holds first.

  • Time

    You watch it search.

    Search, open, read, then open the next file. Pixel gives the agent starting points it can check against the code.

  • Impact

    A match is only the beginning.

    Signatures, callers and related files help the agent understand a change before it edits.

Here’s what the map looks like.

You describe a task. The agent asks Pixel which files to start with, then checks the relevant bodies. These are suggestions, not a complete list of everything the change might touch.

{{/* ---------- how it works ---------- */}}

Local

How it works.

One binary and a folder in your repository. Retrieval runs locally, without a hosted service.

  1. {{ partial "icon.html" (dict "name" "grid" "size" 28) }}

    Index

    .pixel/, at your repository root, holds a text index of eligible files Git does not ignore and a code graph of symbols, imports and calls parsed with tree-sitter, built on first use.

  2. {{ partial "icon.html" (dict "name" "bolt" "size" 28) }}

    Stay warm

    A local daemon keeps both open and follows your edits. No daemon? The command runs in-process.

  3. {{ partial "icon.html" (dict "name" "gauge" "size" 28) }}

    Answer to a budget

    The agent gets the symbols, signatures or lines its question needs, fitted to a token budget, with a marker saying whether the answer is complete.

  4. {{ partial "icon.html" (dict "name" "robot" "size" 28) }}

    Reach the agent

    A CLI plus hooks, not an MCP server. pixel install puts the protocol where each agent reads its instructions, and the agent calls Pixel from the shell it already has.

The index stays on your machine. First use may download an embedding model; Git remotes, classification and web search use the network when requested. Interactive terminals also check for releases. Network details and opt-out
