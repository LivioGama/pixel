Let your coding agent ask the repository instead of reading it.

Pixel is a local index of your code and its Git history. Agents get a ranked answer with its limits stated, not a pile of files to read, and every Git change goes through a crash-safe path.

One path from a task to a pushed commit

The agent prompt that pixel install deploys walks every change through the same steps. Only the edit is left to the agent's own tools.

  1. scope-taskWhich files to open first
  2. find-codeA phrase resolved to the exact symbol
  3. impactEvery caller that could break
  4. editYour agent's own tools
  5. what-changedThe symbols the diff touches
  6. review-changesStaged, unstaged and untracked, structured
  7. commit-and-pushCommit, then a leased push

{{/* ---------- install ---------- */}}

Install in three commands

macOS and Linux. pixel install is global: run it once, from anywhere.

  1. Get the binary

    $ brew install LivioGama/tap/pixel

    Without Homebrew:

    $ curl -fsSL https://github.com/LivioGama/pixel/releases/latest/download/install.sh | sh

  2. Wire it into your agents

    $ pixel install

    Deploys the agent prompt to Claude Code, Codex, Pi, OpenCode and Antigravity. Copilot CLI, Gemini CLI, Devin and Cursor take it as a plugin or rules file.

  3. Check the wiring

    $ pixel doctor .

    Reports the global wiring and this repository's index as green, stale or missing. The first command that needs the index builds it.
