Your coding agent reads whole files. Pixel hands it the answer.

Pixel is a command-line tool your agent calls instead of grep, cat and git log. It indexes your code and its Git history on your machine, answers with the few files and symbols that matter, and says when an answer may be incomplete.

Works with Claude Code, Codex, Cursor, Copilot CLI, Gemini CLI, Pi and OpenCode.

How it works

Nothing changes in how you prompt. Your agent keeps its own tools and uses Pixel's where they answer faster.

  1. Index once

    pixel install wires your agents. The first command in a repository builds its index in .pixel/. In the benchmark below, Pixel's own repository took 9.3 seconds from cold.

  2. Your agent asks

    A hook hands your agent the Pixel protocol when a session starts. Where it would grep or open a file, it runs pixel search-content, pixel scope-task or pixel impact.

  3. It gets an answer with its limits

    Ranked, size-capped results, each marked complete, capped or unresolved. Git writes are crash-safe and never force-push.

On whole agent tasks

Claude Code on real tasks in this repository, with and without Pixel, against a vanilla agent with no rules or hooks.

  • About 30% faster to scope a multi-file task. Two independent A/B designs agree: 31% and 29%.
  • About 1.5 seconds slower on a single lookup in the isolated run: the cost of reading the protocol before a one-shot answer.
  • Still slower at recovering deleted code from history. Open work, measured and published.

Agent A/B runs and their caveats

Where a specialist wins

  • Natural-language search: semble finds the right file in its top 10 for 100% of 45 queries, Pixel for 69%.
  • Compact repository map: stacklit covers more directories for fewer tokens on 3 of 4 repositories.
  • Context cost: Pixel is 4.7× lighter than GitNexus, but heavier than semble (~980 tokens) and stacklit (~420).

They combine: semble for search and Pixel for the graph, history and Git costs about 5,100 always-on tokens. Full comparison

Install in three commands

macOS and Linux. pixel install is global: run it once, from anywhere.

  1. Get the binary

    $ brew install LivioGama/tap/pixel

    Without Homebrew:

    $ curl -fsSL https://github.com/LivioGama/pixel/releases/latest/download/install.sh | sh

  2. Wire it into your agents

    $ pixel install

    Deploys the agent prompt to Claude Code, Codex, Pi, OpenCode and Antigravity. Copilot CLI, Gemini CLI, Devin and Cursor take it as a plugin or rules file.

  3. Check the wiring

    $ pixel doctor .

    Reports the global wiring and this repository's index as green, stale or missing. The first command that needs the index builds it.

Questions before you install

Does my code leave my machine?

No. The index, the code graph and the history data live in .pixel/ inside your repository, and Pixel sends nothing on its own. The network is used only by commands that exist for it, when called: fetch and push to your Git remotes, pixel classify to the model you configure, pixel web-search, and pixel index-unpack from a URL.

Which languages does it understand?

The code graph (callers, impact, call paths) covers TypeScript, JavaScript, Rust, Go, Java, Python, C# and Ruby, plus PHP, C, Swift, Elixir and Lua through a generic extractor. Text search covers every text file under 4 MiB that Git does not ignore.

Does the protocol cost my agent tokens?

About 4,160 tokens on every turn, the prompt that teaches your agent the commands. One pixel impact answer in place of reading a symbol's callers can recover it. GitNexus costs about 19,700 for comparable jobs.

Will it make my agent faster?

On multi-file tasks, yes: scoping measured about 30% faster. On a single lookup it adds about 1.5 seconds. The benchmarks show both.

Which agents does it work with?

pixel install wires Claude Code, Codex, Pi, OpenCode and Antigravity. Copilot CLI, Gemini CLI and Devin load it as a plugin; Cursor, Windsurf, Kiro, Cline and Qoder as a rules file. Setup for each

How do I remove it?

pixel uninstall removes everything pixel install wrote, the binary included. Delete .pixel/ in a repository to drop its index.
