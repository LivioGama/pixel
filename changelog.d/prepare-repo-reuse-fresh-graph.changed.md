**prepare-repo:** keeps a stored graph that still matches the tree, and updates it in place when few files changed, instead of rebuilding it every run: a `.pixel/` restored from a CI cache now costs seconds (3 s on a 60 000-symbol repository, 8 s 40 commits apart). `timings.graph.build` names the mode (`fresh`, `incremental`, `full` and why); `--rebuild-graph` forces the rebuild.
