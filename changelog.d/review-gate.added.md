**graph:** `pixel review-gate` runs a deterministic pre-review of the working tree: `what-changed` plus the mechanical rules an LLM review starts from scratch on — an added line matching a credential-shaped value or secret-named assignment (`possible-secret`, the matched value never echoed), and a changed symbol whose callers were not themselves changed (`producer-reader-divergence`). Every finding carries its witness (file, line, evidence); caps the pass fired ride the epistemics envelope.On a clean feature branch the default base is the merge-base with the remote default branch, so a bare `pixel review-gate` reviews the whole branch diff; a dirty tree still reviews the uncommitted diff. The human render is a findings list — `BLOCKER`/`CONCERN`/`SUGGESTION`/`NIT` (the code-review vocabulary) with file:line, witness and fix — `--json` keeps the raw severities.
