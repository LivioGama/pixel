**daemon, cli:** `pixel search-content` no longer echoes matches from credential-shaped tracked files (`.env`/`*.env`, `credentials.*.json`, `*.pem`/`*.key`/`*.p12`/`*.pfx`/`*.jks`/`*.keystore`/`*.truststore`, `id_{rsa,dsa,ecdsa,ed25519}`, `serviceAccountKey.json`, any file name containing `secret`, extensionless ones included, anything under `secrets/`). The filter runs in the daemon, so it covers every output mode (`--json`, human, `-l`), and the hidden count is surfaced via `epistemics.basis` and a `RESULT_CAPPED` warning.
