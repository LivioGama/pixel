**graph:** `plan`'s `by-concept` path no longer emits one finding per raw concept match. Matches that overlap the prompt only through stopwords and intent verbs ("in", "add", "my") are dropped, and the survivors collapse to a single finding per file — anchored to the enclosing symbol with a match count and evidence snippet — so a "add provider info to status line" prompt yields a handful of file-level checks instead of a 20-item dump of string literals.
