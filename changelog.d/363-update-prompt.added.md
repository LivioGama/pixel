**install:** `pixel` offers the Codex-style close on a terminal: under the daily "a newer pixel is released" line it asks `update now and relaunch? [Y/n]`, runs the upgrade command the notice names (`brew update && brew upgrade LivioGama/tap/pixel` on a Homebrew install, `mise upgrade pixel` on mise, `install.sh` elsewhere) and relaunches the new binary on the same arguments; a decline, a failed upgrade, or any non-interactive stream keeps today's notice-only behaviour, and `PIXEL_NO_UPDATE_PROMPT` turns the question off. ([#363](https://github.com/LivioGama/pixel/pull/363))
