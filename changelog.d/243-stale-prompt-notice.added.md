**install:** after an upgrade, every command except `install`, `doctor` and `uninstall` prints one stderr note when the `agent-prompt.md` or `subagent-prompt.md` that `pixel install` deployed no longer matches the running binary. Agents read those files as they are, so they kept the old release's command map with nothing but `pixel doctor` saying so. Run `pixel install` to clear it ([#243](https://github.com/LivioGama/pixel/pull/243)).
