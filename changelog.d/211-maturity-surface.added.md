- **cli:** `pixel workspace` — multi-repo registry (`add`/`remove`/`list` over `.pixel/workspace.json`) with `--workspace` fan-out on `pixel impact` and `pixel who-calls`: each registered repo is queried and results carry per-repository provenance.
- **cli:** `pixel index-pack` / `pixel index-unpack` — freeze this repo's index into a single checksummed `.pxpack` bundle (manifest + xxhash per file, format-versioned) and install one from a path or `https://` URL, refusing to overwrite a live index without `--force`. The team-shared index story: CI builds once, everyone else installs.
- **cli:** `pixel mcp` — serve this repo's index over MCP stdio: `search`, `resolve`, `impact`, `callers`/`callees`, `evaluate`, `context`, `status` as MCP tools backed by the existing request surface, preserving epistemic statuses and typed failures. One integration for every MCP-capable agent.
- **cli:** `pixel coverage` — per-language index coverage report: files on disk vs files indexed, plus unrecognized extensions, in text or `--json`.
- **cli:** `pixel plan` now persists findings in `.pixel/plan.json` — `--status`/`--done N`/`--undone N`/`--prune` track execution across re-plans without touching the daemon, and completion state survives re-planning.
