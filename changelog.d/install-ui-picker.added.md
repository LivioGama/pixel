**install:** `pixel install` opens an interactive run with the pixel block logo in the site's green, then ends in a rounded summary box — steps word-wrap at 100 columns, the next commands align on one column, and the colored green/yellow/red counts sit inside the box — while `--json` and piped stdout keep the machine-readable report. `pixel config setup` (also offered by `pixel install`) picks every yes/no with the arrows — ←/→ move, Enter confirms, y/n answer outright — Enter at the save question now writes the answers instead of discarding them, and the review renders as aligned rows instead of a JSON dump.
