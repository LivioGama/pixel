**install:** `pixel install` registers Devin's own lifecycle protocol when Devin has been used on the machine (`~/.config/devin/config.json`): `session-start --provider devin`, `prompt-submit --provider devin` and `post-compaction` — until now a Devin session's only Pixel guidance was the imported copy of `~/.claude/settings.json`, and a repo's `prompt-submit --provider devin` alone. The metrics relay stays repo-scoped so it cannot double. `pixel doctor` verifies the entries under the new `install.devin-hooks` check (green-absent on machines without Devin).
