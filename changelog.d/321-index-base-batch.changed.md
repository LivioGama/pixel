**index:** a base or delta built from git sizes every blob with one `git cat-file --batch-check` and streams those under the cap through one `git cat-file --batch` per worker, instead of two git processes per file. On a repository of about 19 000 files, a base build from a cold cache falls from 208 s to 1.9 s on a laptop, with byte-identical base and delta shards. ([#321](https://github.com/LivioGama/pixel/pull/321))
