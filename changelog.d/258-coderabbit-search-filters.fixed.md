**search:** with `-g`/`-t`, `--limit` counts the matching lines printed, not the index rows read before the filter (`--limit 1 -g 'tests/*'` could print nothing), and `--offset` resumes past the rows the filter dropped. The last `-g` matching a path decides, as in ripgrep, so `-g '!*.rs' -g '*.rs'` keeps Rust files; `-l` prints a path once across roots and holds the stdout cap.
