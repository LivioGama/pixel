**pr-swarm:** `scripts/pr-swarm.sh` keeps one rmux pane per open pull request, each a `claude -n pr-<N>-<slug>` session in that PR's worktree, titled `PR#<N> <branch>` and reconciled every five minutes from a SessionStart watcher. A merged PR's pane closes, and its worktree is removed only when it is clean and fully pushed and is not the shared cache; a `CLOSED` PR, a dirty tree, or a failed `gh` call always keeps it. ([#439](https://github.com/LivioGama/pixel/issues/439))
