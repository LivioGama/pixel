**install:** OpenCode joins the enforcing hosts: `pixel install` writes a `tool.execute.before` plugin (`~/.config/opencode/plugins/pixel.js`) that forwards guarded tool ids to `pixel hook guard --provider opencode`, applies a returned rewrite inside `output.args`, and throws on a deny; the guard's shell arm matches OpenCode's lowercase `bash` id, so a wrapped `cat` is judged like the native `read` tool.
