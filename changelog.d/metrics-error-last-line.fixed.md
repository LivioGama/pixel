**metrics:** a failed command now ends stderr on its error. The live 🟩 metrics block used to be the last thing printed, so an agent reading `2>&1 | tail -4` saw the block and not the failure, and a failed `pixel commit` read as a finished one. The `pixel: <error>` diagnostic is repeated after the block and counted as rendered output; `--metrics off` and `PIXEL_METRICS=0` print it once, as before.
