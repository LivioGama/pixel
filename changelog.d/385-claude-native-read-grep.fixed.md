**install:** Claude's PreToolUse guard now reaches the native `Read` and `Grep` tools. The widened matcher (`Bash|Read|Grep`) registers through the existing group, and `pixel run-hook guard --provider claude` emits the same advisory the provider-less legacy path already produces — `pixel search-content` for `Grep`, and `pixel list-signatures` / `pixel search-content` for whole-file `Read` of a source file above the line threshold. `Glob` stays silent by design: blocking path enumeration alone would be noise, and the `Read`/`Edit` of any result is itself guarded. Claude's native permission flow is unchanged. ([#385](https://github.com/LivioGama/pixel/pull/385))
