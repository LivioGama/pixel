**scripts:** the harness runs can now be recorded for a pull request: `scripts/harness-recorder.sh` wraps a Claude Code or Codex run of one of the demo scenarios (or the `rns` retrieval smoke checklist) in an `asciinema rec` session and writes a playable `.cast`, a plain-text transcript and — with `--gif` — an animated GIF under `agg`; `--post <pr>` comments the stats table and transcript on the pull request and attaches the `.cast` as a secret gist for replay, so a reviewer can watch how a Pixel-installed harness behaves without running it.
