**cli:** `pixel mcp` and `pixel list-errors mcp`, the two MCP stdio servers, are removed: Pixel is a CLI plus hooks and extensions. Every tool they served is a command (`search-content`, `find-code`, `impact`, `who-calls`, `evaluate path`, `pack-context`, `status`, `list-errors since|show|query|hmr|env`). The `rmcp`, `schemars` and `tokio` dependencies go with them. ([#392](https://github.com/Pixel-CLI/pixel/pull/392))
