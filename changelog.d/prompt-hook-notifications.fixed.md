**hooks:** The Claude `UserPromptSubmit` hook no longer treats harness-submitted prompts as the user's: a background `<task-notification>`, a slash- or local-command wrapper, or a prompt of nothing but `<system-reminder>` blocks now counts as a continuation, so it neither overwrites the task packet's `Task:` with the XML nor opens a boundary. A human prompt that quotes an envelope mid-text is unchanged.
